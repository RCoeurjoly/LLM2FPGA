Why representative-core SV became huge

PT2E W2A2 changes value ranges, but the imported graph still contains dequantize -> float math -> requantize islands. The graph then expands sharply at CF -> Handshake and again at SV emission.

ExecuTorch question

ExecuTorch usually lowers to backend partitions/delegate artifacts. That can be useful for graph shaping, but opaque delegate blobs are not directly torch-mlir input unless we keep or reconstruct an inspectable tensor graph.
