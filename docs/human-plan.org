** Priority
DDR3-first. The first full TinyStories-1M inference proof should use the
DDR3-backed model/row movement path that can scale to larger TinyStories sizes.
BRAM-only/on-chip targets are diagnostics and regressions.

** Remaining grant tasks
*** TODO Task 6: resource minimization and fitting inference

*** TODO Task 5: scaling to larger TinyStories sizes

Task 6 comes first because Task 3 showed that direct full-model float
compilation does not fit the FPGA. Task 4 and Task 6 converge when the board
returns token-exact TinyStories-1M inference through the resource-reduced path.
Task 5 follows by replaying the same manifest, contract, DDR3, and gate ladder
on larger TinyStories variants.
