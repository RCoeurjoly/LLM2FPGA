** M2 Ladder
- M2.0 artifact discipline: accepted compute submilestones require
  live-compute, direct-mode, strict-readback artifacts. Transport and lifecycle
  submilestones are explicitly non-compute evidence and must say so in their
  contract.
- M2.1 PCIe/BAR contract: direct host writes read back identity for
  input/residual/control without compensated host tricks.
- M2.2 start/clear lifecycle: start_count increments, DONE/ERROR is stable,
  clear returns IDLE, no all-ones/stale BAR.
- M2.3 embedding and block input handoff: host token IDs produce expected block
  input vector and LN input checksum.
- M2.4 live context/attention slice: LN + QKV + softmax/value/context vector
  matches oracle.
- M2.5 attention out-proj + residual + LN2: vector boundaries match oracle.
- M2.6 MLP + final residual: c_fc/GELU/c_proj/final residual match oracle.
- M2.7 full block direct-mode acceptance: one complete TinyStories block from
  token IDs/control to final output matches.

** M3 Ladder
- M3.1 inter-block state movement / DDR3 rowstream contract.
- M3.2 repeated-block execution for a tiny fixed token sequence.
- M3.3 full TinyStories-1M prompt, token-exact greedy output.
- M3.4 repeatability run: same prompt twice after clear/recover.
